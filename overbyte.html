OVERBYTE

Reverse compression. Makes files bigger. On purpose.

// WHAT

OverByte is the opposite of WinZip. Drag a file in. It comes out bigger. You pick the bloat. We deliver.

Why? Maybe you need to fill a disk. Maybe you want to mess with cloud storage limits. Maybe you like absurd software. We don’t ask.

// HOW

// 01

DRAG & DROP

Drop in any file. Pick a multiplier. Click bloat.

// 02

REVERSIBLE

The bloat is meaningful padding. The original file pops back out anytime.

// 03

PORTABLE

One small Windows .exe. No installer if you don’t want one.
